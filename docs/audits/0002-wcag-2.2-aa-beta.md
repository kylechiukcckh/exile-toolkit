# WCAG 2.2 AA beta audit

**Owner:** Exile Toolkit maintainers  
**Reviewed:** 2026-08-25  
**Scope:** Workspace shell, public information pages, and the maps and map-modifier Regex Tool.

Automated axe checks pass in Chromium, Firefox, and WebKit. Browser tests also cover keyboard selection, Tool search, dialog focus, copy feedback, 320-pixel reflow, and reduced-motion behavior.

Manual checks confirmed visible focus, logical keyboard order, text labels alongside status colors, zoom-safe reflow, and selectable copy fallback text. No known WCAG 2.2 AA exceptions remain in the beta scope. Maintainers own any regression found before public release.

This audit does not cover coming-later Tools because they expose no workflow controls.
