# Issue tracker

Exile Toolkit uses GitHub Issues for implementation tickets while retaining local product specifications.

- Product specifications live under `issues/`.
- Implementation tickets live in [GitHub Issues](https://github.com/kylechiukcckh/exile-toolkit/issues).
- Each implementation ticket records its blockers in the ticket body.
- `ready-for-agent` means that a ticket is sufficiently specified for implementation when all blockers are complete. `in-progress` means implementation is underway.

Do not close or rewrite a parent specification when implementing one child ticket. Preserve ticket language and blocking edges when creating or editing implementation tickets.
