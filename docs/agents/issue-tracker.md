# Issue tracker

Exile Toolkit currently uses local Markdown issues.

- Product specifications live under `issues/`.
- Agent-sized implementation tickets live under `.scratch/<feature>/issues/`.
- Each implementation ticket records its blockers in the ticket body.
- `ready-for-agent` is the active triage label and means that a ticket is sufficiently specified for implementation when all blockers are complete.

Do not close or rewrite a parent specification when implementing one child ticket. A hosted tracker may replace these files later without changing the ticket language or blocking edges.
