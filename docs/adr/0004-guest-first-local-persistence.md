# Keep version one guest-first and local

Version one will have no accounts, character import, stash access, or PoE OAuth. Settings, favorites, saved calculations, and bounded history live in the user's browser because the confirmed tools do not require character data and mandatory authentication would add security and operational cost without improving their central workflows.

## Consequences

There is no cross-device sync, and clearing browser data removes unsynchronized work. Shareable safe inputs use versioned URLs; pasted content is not retained unless the user explicitly saves it.
