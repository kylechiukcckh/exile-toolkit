# Require original implementations and explicit data provenance

Exile Toolkit will reproduce useful workflows with original code unless a compatible license clearly permits reuse, and it will not treat public GitHub visibility as permission. Every distributed dataset must record its source, game version, verification state, license metadata, and update time because the referenced tools mix documented APIs, unlicensed repositories, community observations, and GGG-owned generated data.

## Consequences

Some tools will launch with limited coverage or remain marked as coming later. MIT material may be reused with its notices, but a repository-level code license will not be assumed to relicense third-party or GGG-owned data.
